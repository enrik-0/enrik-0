## Vortex

**[Vortex](https://github.com/enrik-0/vortex)** es un framework de backend en Java, pensado para ser rápido, escalable y sencillo de usar. La idea es reducir la fricción a la hora de montar aplicaciones de servidor, con foco en la modularidad.

- Enrutamiento sencillo y flexible
- Configuración dinámica de patrones en endpoints
- Comunicación sencilla entre sistemas HTTP
- Integración con bases de datos relacionales (MySQL)
- Middleware personalizable

Código y documentación en el [repositorio del proyecto](https://github.com/enrik-0/vortex).
